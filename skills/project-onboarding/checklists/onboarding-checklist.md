# Onboarding Reconnaissance Checklist

- [ ] Have top-level directories been cataloged?
- [ ] Have all language runtime versions been documented?
- [ ] Have package managers and dependency trees been identified?
- [ ] Has the local test suite been executed to verify baseline passing state?
- [ ] Have entry points (`main`, web server, CLI) been pinpointed?
- [ ] Have external service dependencies (databases, queues, APIs) been listed?
- [ ] Have repository conventions (linters, formatters, commit formats) been noted?
