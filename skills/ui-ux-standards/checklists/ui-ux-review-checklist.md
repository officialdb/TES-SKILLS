# UI/UX Review Checklist

- [ ] Does the visual design avoid excessive neons, harsh gradients, and decorative clutter?
- [ ] Is there an unambiguous visual hierarchy with one primary action per view?
- [ ] Are typography scales disciplined with readable line heights and line lengths?
- [ ] Does text pass the WCAG AA contrast ratio of 4.5:1?
- [ ] Are all interactive elements accessible via keyboard (`Tab`, `Enter`, `Space`)?
- [ ] Are focus rings clearly visible when tabbing through controls?
- [ ] Has the layout been verified across mobile (375px), tablet (768px), and desktop?
- [ ] Do animations respect `@media (prefers-reduced-motion: reduce)`?
