# Task Completion Checklist

Before reporting completion to the user:
- [ ] Have all intended modifications been applied cleanly without extraneous diffs?
- [ ] Do all existing tests pass?
- [ ] Have new tests been written for newly added logic or edge cases?
- [ ] Have static checks (linters, typecheckers) passed with zero new warnings/errors?
- [ ] Are all newly introduced functions and classes properly typed and documented?
- [ ] Have all temporary debugging statements, scratch files, or print logs been removed?
- [ ] Is the deliverable summary clear, linking changed files and providing verification proof?
